# Adding your own images

Pictures for events and leaders go in these folders:

- Event pictures: `godot/assets/events/`, named after the event's id in `godot/data/content.json` (for example `erland_drought.jpg`)
- Leader pictures: `godot/assets/portraits/`

The Godot version doesn't show them yet; support is planned for the presentation stage. Until then, collect pictures here with a note of where each came from and its licence (public domain or a free licence), so the credits can be written when they go in.
