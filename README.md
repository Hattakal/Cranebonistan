# Cranebonistan

A political election simulator set in the fictional country of Cranebonistan. You found a new party and have five years to become the largest party in the National Assembly. The intended way to win is populism: chasing the votes of whichever groups you can win over, while managing the cost of contradicting yourself.

Runs in any browser with no installation: open `index.html`. Art and licences are listed in [CREDITS.md](CREDITS.md).

## How it plays

- **Four years, weekly turns.** A tracking poll every month, a detailed poll every December, a quarterly budget, the final debate, then the election.
- **Pops.** About 170 population groups (region × age × class × nationality) with views on 8 axes.
- **Manifesto.** One stance per axis. Up to one stance of drift is free; beyond that, voters punish you.
- **Events.** Most months bring one. Choose what to say, then how to say it from real sound bites; the wording shapes your leader's style. Afterwards you see how it played with each group.
- **Agenda.** Each month, open a debate of your own. What you raise comes back as later events.
- **Actions.** Champion an issue, grassroots organising, opposition research, recruit defectors, provoke outrage.
- **The state of the nation.** Jobs, prices, migration, border tension and the public mood drift and push each other.
- **One major crisis** in the second year, from five. Your campaign can make one up to twice as likely.
- **Living rivals, trust in politics, issue ownership, a leader cult.**
- **The final debate and the profile.** Rivals quote you against yourself; at the end a hostile newspaper writes your story.

See [DESIGN.md](DESIGN.md) for every design decision and why it was made.

## Files

| File | What it holds |
|------|---------------|
| `data.js` | The world: balance settings (`CONFIG`), axes, demographics, regions and map shapes, neighbouring countries, parties, campaign channels |
| `events.js` | Monthly events and funding offers, as data. The header explains every effect type |
| `soundbites.js` | What your leader can say in each event |
| `initiatives.js` | The monthly agenda and its consequences |
| `crises.js` | The five major crises |
| `world.js` | State of the nation, agenda, crisis rules |
| `voice.js` | Delivery, style, the record, the debate, the end profile |
| `sim.js` | The rules. No screen code, so it also runs in Node for balance testing |
| `board.js` | The evidence board: the decision waiting for you, the latest poll, staff notes, headlines |
| `scene.js` | The back room: dialogue scenes with Pim and Marta Teyl (the opening one is the tutorial) |
| `map.js` | The map: shapes, label spots and cities. Generated by `tools/build_map.py` from the Krita map; don't edit by hand |
| `ui.js` | Top bar, map, planning files, decision sheets and saving. Reads the state and calls `sim.js` |
| `sfx.js` | Sound effects, synthesised in code |
| `icons.js` | Line icons used for party emblems and buttons |
| `portraits.js` | Draws leader portraits from a name, sex and age |
| `flags.js` | National flags |
| `art.js` | Event illustrations, and which event uses which picture |
| `images.js` | Your own pictures for events and leaders (see [IMAGES.md](IMAGES.md)) |
| `style.css` | The look |
| `index.html` | Page skeleton |

The whole game is one plain object (`state`), saved to the browser's local storage.

## Setting

Cranebonistan has five regions: Cranbia (capital Cranebo, industrial and educated), Yamlin (trade gateway, mixed and tense), Erland (nationalist breadbasket), Alinni (conquered from the Southern Trueants fifty years ago, minority-heavy) and Fauran (nomadic, poorest). Its neighbours are the Southern Trueants, the Dillihan Republic, the Bordon Federation and James. Further away are Golba, Norbanistan and Potania.

## Updating the map

The map is drawn in Krita (layers: Background, States and Countries, Rivers and Mountains, Cities, and a text layer with the city names). To rebuild the game's map from a new version:

```
python3 tools/build_map.py path/to/map.kra
```

This rewrites `map.js` and `assets/map-features.png`. It needs Python with numpy, scipy, opencv-python and Pillow. If a border is moved so much that an area no longer contains its seed point, adjust `AREA_SEEDS` at the top of the script.
